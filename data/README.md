# 数据与模型研究

公开仓库只保存 `scripts/` 中的研究代码。完整编目、SHP、CTX 影像、人工审核记录、数据划分和模型产物分别保存在本地 `raw/`、`processed/`、`manifest/`、`runs/`、`weights/` 等目录，不随源码提交。

人工修框与原始 SHP 外接框分开保存；排除、暂扣、背景确认及目标来源记录不能用原 SHP 覆盖。裁片按空间来源划分训练、验证与测试，同一滑坡的重复裁片不能跨集合使用。是否满足隔离条件仍需结合实际清单核验。

入口与运行限制见 [脚本说明](scripts/README.md)，对外演示数据沿用根目录 `examples/`。
