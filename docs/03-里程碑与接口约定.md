# 里程碑与接口约定

课程周期按 **4 周** 排。若老师截止日期不同，只压缩冲刺项，不压缩第 1–2 周。

## 周计划

### 第 1 周：能存、能查、能看见点

- 崔亚鹏：GitHub 建库、保护 `main`、Docker Compose、Django 空项目、滑坡列表/详情接口、跨域。
- 滕佳杰：锁数据源，拿下样本 CSV，清洗脚本第一版，MySQL 能进 50+ 条。
- 梁先楷：Vite + Vue 骨架、大屏布局、地图底图、用 mock 画点。
- 周璇：定预测特征；准备 10 篇中文说明文本给 RAG；写 5 个标准问题。

**周验收：** 浏览器打开页面能看到数据库里的点，而不是写死的假坐标。

### 第 2 周：图谱 + 预测推荐

- 滕佳杰：Neo4j 实体入库，子图能查；提供 fallback JSON。
- 崔亚鹏：`/api/graph/subgraph/`、`/api/stats/overview/`、`/api/predict/`、`/api/recommend/` 挂上。
- 周璇：sklearn 训练并导出 joblib；推荐用特征距离或图谱 `SIMILAR_TO`。
- 梁先楷：统计图、详情抽屉、图谱网络图（ECharts graph）。

**周验收：** 点一条滑坡，能看到类型预测或相似推荐，图谱有邻节点。

### 第 3 周：智能体 + 多模态

- 周璇：Chroma 入库，LangChain 调用通义千问，问答返回引用 ID。
- 梁先楷：对话框、语音 5 指令、移动端布局；手势按进度。
- 崔亚鹏：Redis 缓存统计和问答；接口分页和错误体统一。
- 滕佳杰：补爬虫脚本、数据字典、Cypher 说明。

**周验收：** 5 个标准问题都能答；语音能切换图表或发起提问。

### 第 4 周：打磨交付

- 全组联调演示脚本（控制在 1 分 50 秒内，留余量）。
- 周璇出报告初稿和视频脚本；梁先楷出镜或录屏；崔亚鹏清 Git 历史、写 README 启动步骤。
- 砍未完成的手势/3D，不要在视频里承诺现场没有的功能。

## 接口冻结（第 1 周末前不得擅自改 URL）

基址：`http://127.0.0.1:8000/api`

公共约定：

- JSON，UTF-8，字段 snake_case
- 列表：`{ "count": N, "page": 1, "page_size": 20, "results": [ ... ] }`
- 错误：HTTP 4xx/5xx + `{ "detail": "中文原因" }`
- 筛选空结果返回 200 和空 `results`，不要 404

### `GET /api/landslides/`

Query：`type`、`region`、`min_lat`、`max_lat`、`min_lon`、`max_lon`、`page`、`page_size`

`results[]` 最少字段：

```json
{
  "id": "ls_0001",
  "name": "example crater wall",
  "type": "slump",
  "lat": 12.3,
  "lon": -45.6,
  "length_m": 1200,
  "mission": "MRO"
}
```

### `GET /api/landslides/{id}/`

详情在列表字段上增加：`width_m`、`features`、`description`、`source_url`。

### `GET /api/stats/overview/`

```json
{
  "total": 0,
  "by_type": [{"type": "slump", "count": 0}],
  "by_mission": [{"mission": "MRO", "count": 0}]
}
```

### `GET /api/graph/subgraph/`

Query：`id`（滑坡 id）、`depth`（默认 1，最大 2）

```json
{
  "degraded": false,
  "nodes": [{"id": "ls_0001", "label": "...", "kind": "Landslide"}],
  "edges": [{"source": "ls_0001", "target": "type_slump", "rel": "IS_TYPE"}]
}
```

### `POST /api/predict/`

```json
{"lat": 12.3, "lon": -45.6, "length_m": 1200, "slope_deg": 18}
```

```json
{"pred_type": "slump", "proba": {"slump": 0.72, "fall": 0.21, "flow": 0.07}}
```

特征以周璇第 1 周冻结的列为准，缺列允许为 null。

### `GET /api/recommend/`

Query：`id`、`top_k`（默认 5）

```json
{"items": [{"id": "ls_0008", "score": 0.83, "type": "slump"}]}
```

### `POST /api/agent/ask/`

```json
{"question": "火星上主要有哪些类型的滑坡？", "top_k": 5}
```

```json
{
  "answer": "...",
  "citations": [{"id": "ls_0001", "title": "..."}],
  "degraded": false
}
```

## 语音词表（梁先楷维护，其他人按词接）

| 说法 | 动作 |
| --- | --- |
| 放大 / 缩小 | 地图 zoom |
| 切换图谱 | 打开图谱页或面板 |
| 切换统计 | 打开统计页 |
| 有哪些滑坡类型 | 调用 `/api/agent/ask/` |
| 推荐类似滑坡 | 对当前选中 id 调 `/api/recommend/` |

新增说法先改这个表，再改代码。

## 联调纪律

- 前端开发前两天可以用 mock，但 mock 的字段必须等于上表。
- 改字段开 issue 或在群里同步，并改本文档同一天提交 `docs:` commit。
- 后端先返回假数据也行，URL 和字段先稳定。
