# 系统架构

## 一句话

浏览器里的 Vue 大屏，只跟 Django 说话；Django 再去问 MySQL、Neo4j、Redis、sklearn 和 RAG。

```
[PC 浏览器 / 手机浏览器]
        |  HTTP JSON
        v
   Django + DRF
     |     |      |         |
     v     v      v         v
   MySQL  Neo4j  Redis   ai/ (sklearn, Chroma, 通义千问)
     ^
     |
  data/ 清洗入库脚本
```

## 目录怎么分

```
Mars-KG-Vis/
  backend/          # 崔亚鹏  Django 项目
  frontend/         # 梁先楷  Vue3
  data/             # 滕佳杰
    raw/            # 原始文件，大文件不进 Git
    processed/      # 清洗结果、graph_fallback.json
    scripts/        # 下载、爬取、清洗、入库
    graph/          # 实体关系定义、Cypher
  ai/               # 周璇
    models/         # sklearn 训练脚本与 joblib
    rag/            # 切片、入库、检索、生成
    eval/           # 几个标准问题的评测
  docs/
  docker-compose.yml
```

前端不出现 Neo4j 驱动、不出现 DashScope Key。算法脚本可以单独跑，但产品路径必须经过 Django。

## 运行时职责

**Django 应用划分（建议）**

- `landslides`：滑坡 CRUD、筛选、详情
- `graph_api`：子图查询，封装 Neo4j
- `analytics`：统计、预测、推荐
- `agent`：RAG 问答（同步请求即可，课设不必上 Celery）

**MySQL 存什么**

面向列表、筛选、统计、预测特征的宽表。一行一条滑坡。类型、任务、文献做成字典表或 JSON 字段，不要一上来范式拆十张表。

**Neo4j 存什么**

实体：`Landslide`、`LandslideType`、`Region`、`Mission`、`Feature`、`Paper`。  
关系：`IS_TYPE`、`LOCATED_IN`、`OBSERVED_BY`、`HAS_FEATURE`、`SIMILAR_TO`、`MENTIONED_IN`。

MySQL 是主库（丢了可以重入）；Neo4j 是关系视图。两边的滑坡 ID 必须同一套。

**Redis 存什么**

- `stats:overview` 大屏汇总
- `agent:qa:{hash}` RAG 答案短缓存
- 列表筛选的热点查询（可选）

没有 Redis 时接口仍要能返回，只是慢一点。

**Chroma 存什么**

清洗后的滑坡说明、类型百科、少量论文摘要。metadata 带 `landslide_id`、`type`，方便引用回表。

## 关键用户路径

1. **看分布：** 打开大屏 → `GET /api/stats/overview/` + `GET /api/landslides/?bbox=` → Leaflet 撒点。
2. **看一条：** 点标记 → `GET /api/landslides/{id}/` → 右侧详情；同时 `GET /api/graph/subgraph/?id=` 画邻域。
3. **预测：** 表单填坡度/纬度/尺度等 → `POST /api/predict/` → 类型 + 概率；推荐位 `GET /api/recommend/?id=`。
4. **提问：** 输入或语音 → `POST /api/agent/ask/` → 回答 + 引用的滑坡 ID，前端高亮地图。
5. **语音：** 浏览器把文本丢给同一套按钮逻辑（「放大」「切换图谱」「火星上有哪些滑坡类型」）。
6. **手势：** 仅 PC，映射到地图 zoom/rotate，失败则忽略，不影响鼠标。

## 降级

| 依赖挂了 | 行为 |
| --- | --- |
| Neo4j | 子图接口返回 `graph_fallback.json`，响应头或字段标记 `degraded: graph` |
| DashScope | 命中 5 条 FAQ；否则返回「智能体暂不可用」+ 仍给出检索到的条目 |
| Redis | 直查 MySQL |
| 摄像头 / MediaPipe | 隐藏手势入口，语音和鼠标仍在 |
| 移动端麦克风权限 | 显示文字输入 |

## 环境

Python 3.10+（后端、数据、AI 共用一个 conda/venv 即可）。Node 18+。Docker 只跑 MySQL、Neo4j、Redis。前端和 Django 本机跑，方便热更新。

密钥：`DASHSCOPE_API_KEY`、`NEO4J_PASSWORD`、`MYSQL_PASSWORD` 放 `.env`。仓库给 `.env.example`。
