# 第 5 周后端交付：CTX 裁图检测接四分类

已接入 YOLOv8n 单类检测和现有 DINOv2 四分类。用户上传受限的 CTX 裁图后，服务按设备凭据创建任务。查询结果提供原图像素框、检测分数、每框四类分数及模型版本。有效输入宽高均不超过 2048 像素，每次最多返回 12 个候选。字段与错误处理见[检测接口约定](../../contracts/detection.md)。

11 月 17 日已用本机真实权重验证完整 API 流程。将一块真实 CTX 裁图放入 1800×1500 像素测试画布，CPU 返回 2 个候选，均有四类分数和待复核标记。预览与输入尺寸一致，另一设备请求同一任务返回 404。最终代码实测从提交到完成约 1.75 秒，服务初始化约 21 秒。该输入用于验证接口、坐标和模型连通性，检测精度与实际运行耗时仍需独立评估。

API 回归 104 项通过，覆盖跨窗口坐标还原、重复框去除、候选上限、设备隔离、历史兼容和任务状态。
