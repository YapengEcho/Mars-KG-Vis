# 检测与四分类研究

研究流程为 CTX 裁片 → 单类滑坡检测 → 候选框裁图 → SL／SP／FL／CL 四分类。背景过滤、裁图尺度、类别重平衡、模型微调和候选融合均作为受控对照，不能仅凭单次最高结果替换参照。

本次整理加入人工标注、数据导出、YOLO／P2 历史基线、DINOv2／CNN 分类对照、真实检测框联评及独立回算入口。移动端和 FastAPI 继续沿用已有实现；目前 API 未接入这些研究权重。

## 评估口径

- 使用地理及像素来源分组，保留独立滑坡编号；同一编号的多次出现不能当作多个独立目标。
- 检测比较使用相同开发图、匹配规则及候选预算；分类关注 macro-F1 和逐类指标。
- 联合评估要求框匹配且类型正确，全部保留候选都计入精确率分母。
- 重复使用的开发集用于选方案，不能替代最终独立验收；随机种子重复也不能代替新增空间测试。
- 人工框和 SHP 框保留来源区别，专家类型不因模型预测而自动更改。

## 最近已核验的结果

2026 年 10 月 25 日，YOLOv8n 的 AdamW／SGD 双种子对照及固定 DINOv2 三种子联评完成。单独更换优化器没有稳定的整体优势；固定名次融合在相同候选预算下有小幅收益。

| 总候选预算 | SGD 单模型 | AdamW 单模型 | 固定融合 |
|---|---:|---:|---:|
| 300 | 41.17 | 43.33 | 45.33 |
| 600 | 53.50 | 56.17 | 61.00 |
| 1071 | 64.50 | 64.50 | 69.50 |

表中是两个检测种子、三个分类种子的“定位且类型正确的不同滑坡数”平均值，开发集含 183 个独立滑坡。1071 候选预算下去重联合召回约由 35.2% 升至 38.0%；它不是检测 AP，也不是分类准确率。融合仍未解决 FL、CL 识别薄弱的问题，运行两个检测器的实际耗时尚未测量。

完整口径、局限及回算入口见 [本轮报告](../86-优化器双种子复测结果与分类联评-20261025.md)。报告提到的协议、预测、权重和运行记录按私有研究产物管理，公开源码不包含这些文件。
