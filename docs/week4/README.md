# 第4周后端交付：单图分类与识别记录

本周范围为 11 月 9—15 日的单图分类后端。已将现有四分类权重接入 API，固定预处理，并提供异步任务、结果持久化与设备间访问隔离。

| 交付 | 实现 |
| --- | --- |
| 真实四分类 | DINOv2-base＋最后两块 q/v rank4 LoRA＋线性头，离线加载私有权重和标准化参数 |
| 固定预处理 | 灰度三通道、224 等比例补边、ROI 面积加权汇总及固定训练标准化 |
| 结果约定 | SL/SP/FL/CL 四类分数、候选类型、待复核原因、模型与预处理版本 |
| 任务与记录 | 接受上传后返回任务编号，支持查询、分页回看、授权预览和删除 |
| 访问隔离 | 随机设备凭据，库内只存哈希；跨设备读取／删除与不存在记录统一返回 404 |
| 生命周期 | 工作队列限额、单工作进程锁；重启保留已完成结果，未完成任务明确标为失败 |

## 验证与边界

95 项 API 测试通过，覆盖输入限制、ROI、任务状态、失败处理、访问隔离、删除、重启恢复及资源哈希。CI 使用合成图片和替代推理器，不加载私有模型。

另以本机既有权重和一张训练裁片做真实推理及 HTTP 端到端验证：CPU 两线程单次约 0.7 秒，冷启动约 22 秒；与既有离线四类分数的最大差约 0.0000025。设备隔离及重启读回通过。此检查验证实现一致性，不是准确率评估，也没有读取评估集或启动新训练。

当前所有结果保留待复核；分数未经校准。模型只分类已裁好的单滑坡图，检测大图、自动确认地质类别和账号同步未包含在本周后端交付中。
