## 3. 页面字段与来源

| 页面元素 | 来源 |
| --- | --- |
| 标题、副标题、区域、图幅、尺度 | `atlas.json` 的 `cases` |
| 观察要点 3 条、标签 2 个 | `atlas.json`，按“先看什么→再看什么→别误读什么”写 |
| 目录记录（编号/经纬度/面积/来源） | 运行时按 `landslideId` join 目录；关联不到时显示说明 |
| 引用 | `citationLocator`（论文 3.2.x 节 + 表 2） |
| 前后切换 | 同类型案例顺序，最后一例只有“上一个” |
| 定位/收藏 | 复用探索页的 `?focus=` 与 `mars-atlas:saved:v1` |

## 4. 观察要点怎么写（避免注水）

每条都落到“图上能看什么”，不写“该滑坡具有重要的科学意义”这类空话。三类句式：

1. **判据句**：如 SL “堆积体已离开坡脚、前缘向外铺展，这是 SL 与 SP 的分界”。
2. **尺度句**：如 190.9 m/像素下“纹理只能看走向，不要评粗细”，提醒读者别把分辨率差异当形态差异。
3. **对照句**：如“与同图幅 CL 案例 ls_0482 对照：一个有下部远程堆积，一个没有”。

## 5. 核对结果

- 12 条 `landslideId` 与目录一一对应（`atlas-export-summary.json` 里 `casesInCatalog: 12`，前提是接完整目录）。
- 12 条的类型与目录 `type` 一致（目录为 SL/SP/FL/CL 四类，不做二次映射）。
- 引用位置全部指向论文中真实存在的小节/表/图；页码为 PDF 物理页。
- 未决：12 例是否“典型”、公开范围（公开子集只有 8 个 source id），需要老师确认后才能对外展示坐标与影像。
