完整2971条目录、原始SHP、其余裁片、完整人工标注、源图幅和模型权重仍单独交接，不随源码公开。此处提供小范围项目示例，不代表完整编目或源影像已获开放发布授权。

真实记录的源纬度约定尚待核准。APP与API默认将此子集映射为`mode=reference`，保持原始数值、不做纬度转换，球面和详情标明位置仅供参考。源文件保持不变，不将其冒充坐标已核准的`mode=catalog`正式版本。核准后再按contracts/catalog.md导出正式目录。

真实样例分类参考：[火星全球滑坡编目及分类初探](https://doi.org/10.13203/j.whugis20250300)。sourceId保留原始序号，类名来自已有编目，不是本项目模型的预测。
