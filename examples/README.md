# 示例数据

|文件|内容|用途|
|---|---|---|
|catalog.demo.json|20条虚构记录，明确标记demo|默认APP和API运行、组件及接口测试|
|catalog.real-subset.json|8条真实字段样例，SL／SP／FL／CL各2条|字段对照和编号关联参考，不是完整目录|

完整2971条目录、原始SHP、人工标注、研究影像和模型权重单独交接，不随源码公开。真实字段样例只包含本文件明确列出的8条，不含图片、原始边界或其余记录。

真实样例的源纬度约定尚待核准，文件使用reference状态，不满足正式Catalog运行契约，不能直接替换默认演示目录。核准坐标并完成资料整理后，再按contracts/catalog.md导出正式版本。

真实样例分类参考：[火星全球滑坡编目及分类初探](https://doi.org/10.13203/j.whugis20250300)。sourceId保留原始序号，类名来自已有编目，不是本项目模型的预测。
